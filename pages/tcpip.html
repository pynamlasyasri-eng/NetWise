TCP/IP MODEL

Explore the four layers that make Internet communication possible.

What is the TCP/IP Model?

TCP/IP stands for Transmission Control Protocol / Internet Protocol. It is a networking model that explains how data travels between devices across interconnected networks, including the Internet.

The model contains four layers. Each layer performs a specific task during network communication.

Four Layers of TCP/IP

04

Application Layer

Provides network services to applications. It supports web browsing, email and file transfer.

HTTP | HTTPS | DNS | FTP | SMTP
03

Transport Layer

Provides communication between applications on different devices. It handles segmentation and delivery of data.

TCP | UDP
02

Internet Layer

Handles logical addressing and routing. It helps packets travel from the source network to the destination network.

IPv4 | IPv6 | ICMP
01

Network Access Layer

Handles the transmission of data over local networks using wired or wireless communication technologies.

Ethernet | Wi-Fi

TCP vs UDP

TCP and UDP are two important protocols used at the Transport Layer.

Feature TCP UDP
Connection Connection-oriented Connectionless
Reliability Reliable delivery No delivery guarantee
Speed Generally more overhead Generally lower overhead
Example Uses Web browsing, file transfer Live streaming, online gaming

Applications of TCP/IP

Web Browsing

Enables browsers to communicate with web servers using HTTP and HTTPS.

Email

Supports sending and receiving emails using protocols such as SMTP and IMAP.

File Transfer

Allows files to be transferred between devices using protocols such as FTP.

Online Communication

Supports real-time applications such as online games and voice communication.
