NETWORK FUNDAMENTALS

OSI & TCP/IP Models

Understand how data travels between devices through network layers.

OSI Reference Model

The OSI model divides network communication into seven layers. Each layer performs a specific function to help data travel from one device to another. Click on any layer to learn more.

7. Application Layer

The Application Layer provides network services directly to user applications. It allows applications to communicate over a network.

Examples: HTTP, HTTPS, FTP, DNS and SMTP.

TCP/IP Model

The TCP/IP model is used for communication across the Internet. It organizes networking functions into four layers.

4. Application

Provides services for applications and user communication. Examples: HTTP, DNS, FTP and SMTP.

3. Transport

Handles end-to-end data delivery. Examples: TCP and UDP.

2. Internet

Handles logical addressing and routing of packets. Example: IP.

1. Network Access

Handles communication over the physical network. Examples: Ethernet and Wi-Fi.
